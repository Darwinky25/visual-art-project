# Backup Files

This directory contains backup versions of files created during development.

## Contents

- `App.tsx.backup` - Previous version of main App component
- `App.tsx.backup.tabbed` - Tabbed interface version of App component

## Purpose

These files are kept for reference and rollback purposes but are not used in the build process. They document the evolution of the application's architecture.

## Note

All backups are also preserved in Git history. You can safely delete these files if you no longer need local copies.
